# Clinic Appointment Portal — Static Demo

Static HTML version of the Laravel clinic website (for portfolio / Vercel).
 link https://drweb-k7ie-git-main-anuja-chavan.vercel.app/


Forms show a "demo submitted" message and save nothing.

Full Laravel + MySQL source: https://github.com/anuja2793/clinic-appointment-portal

## Deploy on Vercel
Push this folder to a GitHub repo, then Vercel -> Add New -> Project -> Import.
Framework Preset: Other. No build command, no output directory.
